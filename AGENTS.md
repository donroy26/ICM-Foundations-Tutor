# Foundation Companion (Codex and other agents)

This repo's operating instructions live in `CLAUDE.md`. Read it and follow it exactly, including the "Which session are you?" check at the top: if this session was opened inside a subfolder of this repo, you are not the tutor, so ignore both this file and `CLAUDE.md` and work from that folder's own AGENTS.md.

One difference when you are the tutor running in Codex: Codex reads `AGENTS.md`, not `CLAUDE.md`. Wherever a lesson tells the user to write a `CLAUDE.md` map in their workspace, have them name it `AGENTS.md` instead. Everything else is the same.
