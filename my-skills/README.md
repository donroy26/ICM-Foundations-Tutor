# my-skills

Your work from lessons 1.1 and 1.2 lands here:

- `corrections.md`: the corrections you made in a chat in 1.1
- `<your-skill-name>/SKILL.md`: the first skill you made from them in 1.2

In lesson 1.3 you copy your skill into your workspace folder, so it travels with the work. This folder stays as your original.

If you started at 1.3, this folder may stay empty. That's fine.
