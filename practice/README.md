# Practice folders

These are Jake Van Clief's Foundations practice folders, the same ones used in the lesson videos. They come from the Start Here page of the Foundations course in the Clief Notes community (`foundations-practice-folders.zip`), included here so the tutor works on clone. Everything in them is made up for a demo.

| Folder | Used in | What it is |
|---|---|---|
| `client-email/` | 1.3, 2.3, 3.3 | answering client emails: notes per client, an inbox, the how-i-reply skill, and Jake's finished map |
| `tiny-test/` | 1.4 | one file, for the tiny test that proves your setup works |
| `weekly-report/` | 2.1, 3.1, 3.2 | a weekly bookings export turned into a summary table, with last week's summary made by hand |
| `newsletter-mess/` | 2.2 | a deliberately messy folder to design into a workspace |

**Don't work in here.** When a lesson needs one of these, the tutor copies it to the root of the Foundation Companion folder and you work on the copy. These stay clean so you can always start over.

If you'd rather use your own work, that's better still. Use a copy of it the first time.
