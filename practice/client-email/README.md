# Practice folder: client-email

A made-up folder of client work, shaped like the one in the Foundations videos. Use it if you don't have a folder of real work handy, or want a safe first run.

Everything in here is invented. The clients, the emails and the bookings are not real.

In lesson 1.3 your tutor will have you copy this whole folder to the root of the Foundation Companion folder, so you always have a clean original here to start over from.

What's inside:

- `about-me.md`: who "you" are and how you work
- `clients/<client>/notes.md`: what's been agreed with each client
- `inbox/`: emails waiting for a reply
- `drafts/`: empty, replies go here
- `exports/`: two weeks of bookings exports from a booking system

There's no `CLAUDE.md` yet. Writing it is the lesson.
